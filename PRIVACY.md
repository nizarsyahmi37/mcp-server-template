# Privacy Policy

This template is a starting point. If you publish a server built from it, replace the
placeholders below with details that are accurate for your server.

## Data collected

The example server (`echo`, `add`, and the sample resources and prompt) processes the
inputs it receives only to produce a response. It does not store, log, or transmit that
data, and it makes no network requests.

## Third parties

The example server shares no data with third parties.

## Your server

If your tools call external APIs, write to disk, or keep logs, document here:

- what data is collected and why
- where it is stored and for how long
- who it is shared with
- how users can request deletion
